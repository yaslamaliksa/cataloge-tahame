# كتالوج روابي تهامة التفاعلي

عارض ثابت جاهز للنشر، يعرض غلافًا أماميًا وخلفيًا منفردين وصفحات داخلية متقابلة من اليمين إلى اليسار، مع تأثير تقليب الورق والظلال وصوت تقليب قابل للكتم.

## رفع الملفات على GitHub Pages

1. فك ضغط ملف `rawabi-github-files.zip` على جهازك.
2. أنشئ مستودعًا جديدًا في GitHub. اختر **Public** إذا كنت ستنشره باستخدام GitHub Pages المجاني.
3. من **Add file → Upload files** ارفع محتويات المجلد كاملة، بما فيها مجلد `assets`. يجب أن يكون `index.html` في جذر المستودع، وليس داخل مجلد إضافي. احفظ الملفات باستخدام **Commit changes**.
4. افتح **Settings → Pages**.
5. في **Build and deployment** اختر **Deploy from a branch**، ثم اختر الفرع **main** والمجلد **/ (root)** واضغط **Save**.
6. بعد اكتمال النشر، سيظهر رابط الموقع في صفحة الإعدادات. غالبًا يكون على الشكل: `https://USERNAME.github.io/REPOSITORY/`.

لا يحتاج المشروع إلى Node.js أو npm أو مفاتيح API أو خطوة بناء. الروابط نسبية لتعمل داخل مستودع GitHub Pages. رابط GitHub Pages مستقل عن رابط المعاينة الخاص في ChatGPT؛ إعدادات مستودعك هي التي تحدد وصول الزوار.

## الاستخدام

- اسحب طرف الورقة أو اضغط الأسهم للتقليب. تبقى الصفحات الداخلية بصفحتين متقابلتين حتى على الشاشات الصغيرة.
- يبدأ الكتاب بالصفحة 1 وحدها كغلاف أمامي. عند فتحه تظهر الصفحتان 2 و3، ثم 4 و5، وصولًا إلى 18 و19. تظهر الصفحة 20 وحدها كغلاف خلفي. الصفحة الداخلية الأسبق تظهر على اليمين.
- اكتب رقم أي صفحة للانتقال إلى الغلاف أو الزوج الذي يحتويها، أو استخدم الصور المصغّرة.
- زر التكبير يفتح الغلاف وحده أو الصفحتين الداخليتين بحجم كبير مع إمكانية التمرير. اضغط × أو Escape للعودة.
- زر الصوت يفعّل أو يكتم صوت الورق، ويحفظ اختيارك في المتصفح. يعمل الصوت بعد أول تفاعل، وفق سياسة المتصفح.
- زر ملء الشاشة يعمل في المتصفحات التي تدعم هذه الخاصية.
- زر التنزيل يحفظ نسخة PDF الأصلية.

## معاينة محلية

شغّل خادم ملفات محليًا من مجلد المشروع، ثم افتح الرابط في المتصفح:

```sh
python -m http.server 8000
```

الرابط: `http://localhost:8000`.

## الملفات

- `index.html` — واجهة العارض.
- `style.css` — التنسيق والتجاوب.
- `app.js` — عرض الصفحتين، القراءة العربية، الصوت والتنقل.
- `catalog.pdf` — الكتالوج الأصلي، 20 صفحة.
- `assets/logo.svg` — نسخة متجهة معاد رسمها من الشعار المرجعي المرسل.
- `assets/page-01.webp` إلى `page-20.webp` — صفحات الكتالوج.
- `assets/thumb-01.webp` إلى `thumb-20.webp` — الصور المصغّرة.
- `assets/page-turn.wav` — صوت ورق مولّد خصيصًا لهذا العارض.
- `assets/page-flip.js` — مكتبة StPageFlip 2.0.7، محفوظة محليًا.
- `assets/arabic-*.ttf` — ملفات الخط العربي المحفوظة محليًا.

الصور والخط والصوت ومكتبة التقليب مضمنة، ولا يعتمد التشغيل على CDN.
